# MindManager files saved by MindManager

Real `.mmap` archives, used to check the MindManager importer against what MindManager writes
(see `MindManagerRealFiles.test.ts`). They are third-party files, kept unchanged under their
licences: MIT (below) or Apache 2.0 (`LICENSE-APACHE-2.0.txt`).

## blumind-mm8.mmap

- Source: https://github.com/funwaywang/Blumind, `Documents/MindManagerMaps.mmap`
- Saved by MindManager 8 (`<ap:Version Major="8"/>`) in 2011.
- Licence: MIT
- Copyright (c) 2010~2017 funwaywang

## mmap2json-2017.mmap

- Source: https://github.com/lonjoy/mmap2json, `mmap/test.mmap`
- Saved by MindManager in 2017.
- Licence: MIT
- Copyright (c) 2017 舒俊杰 (lonjoy)

## mindm-test-dom-mm23.mmap

- Source: https://github.com/robertZaufall/mindm, `examples/Test_DOM.mmap` (commit
  fbd3e79f30d428322c588278c27b76c6abce7860)
- Saved by MindManager 23.0 for macOS (`<?xml-client name="MindManager" version="23.0.169"?>`) in 2025.
- Has colours, a web link and a link to a topic, a custom icon, stock icons, notes and
  relationships.
- Licence: MIT
- Copyright (c) [2026] [Robert Zaufall] (as written in its LICENSE)

## jvm-classloader-mm2016.mmap

- Source: https://github.com/13543004741/mindjetMindManager, `JVM加载器.mmap` (commit
  6378fc07e58673752ce754a91c5f22f35a289f14), renamed.
- Saved by MindManager 2016 (16.0.159, in the ZIP comment) in 2016.
- Has floating topics, relationships and relationship labels.
- Licence: Apache License 2.0, see `LICENSE-APACHE-2.0.txt`. Its LICENSE has no copyright
  line; the copyright holder is the GitHub user 13543004741.
